# HelioFlux illustration assets — final revised style

13 transparent WebP web derivatives of generated PNG masters, created 10 November 2026. This set supersedes earlier realistic and cartoon explorations.

Style: fine blue scientific contour drawings based on user-supplied screenshots of the science and timeline pages, largely white/unfilled clothing and furniture, tiny sage accents, selective natural skin/hair color. Maya is a fictional South Asian-inspired woman with warm brown skin and dark wavy hair; her clinician is fair-skinned and blonde.

## Use
All WebP files retain real alpha transparency and original dimensions. They are quality-92 compressed derivatives; original PNG masters were delivered separately. Place on white/warm off-white for best results; soft translucent edge washes are present. Use contain rather than cropping hands/faces. Portrait files 02 and 03 are 1024×1536; the others 1536×1024.

These are illustrative fictional scenes, not photographs, patient evidence or authenticated product hardware. Patient-facing scenes should be framed as an illustrative journey, not an available validated HelioFlux clinical service. Cell emission is conceptual, not measurement data. Decorative notebook curves are not actual findings. Do not attach claims of diagnostic validation, fixed scan duration, cell thresholds, avoiding biopsies, treatment effectiveness or guaranteed outcomes. All figures should be reviewed with captions in context before public use. Included on a GitHub review branch only; not deployed to the public website.
